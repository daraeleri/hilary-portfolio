# Tangunu Hilary — Portfolio

Personal portfolio for **Tangunu Hilary**, built with Next.js (App Router), TypeScript and Tailwind CSS v4.

## Skills showcased

- Networking
- Network security
- Ethical hacking
- Mobile development
- Web development

## Design direction

- **Palette:** black, white, blue (tokens in `src/app/globals.css`: `ink`, `paper`, `blue`, `blue-soft`, `muted`, `line`)
- **Main style & overall inspiration:** https://beetogreen.com/en
- **About section:** section 08 of https://www.learn3d.ai/en/ai-x-3d-environments
- **Footer style:** https://www.logomint.co/

## Assets

- `public/images/hilary.png` — portrait photo

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Scripts

| Command         | What it does              |
| --------------- | ------------------------- |
| `npm run dev`   | Start the dev server      |
| `npm run build` | Production build          |
| `npm run start` | Serve the production build |
| `npm run lint`  | Run ESLint                |
